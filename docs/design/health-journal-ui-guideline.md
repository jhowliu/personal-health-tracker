# 健康手帳 UI 配色與風格 Guideline

版本：1.1 · 更新日期：2026-10-09

本規格依目前互動預覽整理，涵蓋今天、身形、餐點、訓練與設定五個頁面。介面中的熱量、營養素與身形數值為展示資料。

## 1. 風格定位

**柔和手帳感、簡約清楚、少量俏皮。** 使用暖米白底色、莓紅主色、柔和的分類底色，以及清楚的灰黑文字與細分隔線。

- 以留白、字級與對齊建立層級；一個群組使用一個容器，列內用細線分隔。
- 圓角與線條保留手帳感；主要操作使用莓紅，狀態與分類使用小面積淡色。
- 日期、頁面標題、餐點名稱、訓練名稱與主要數值統一使用灰黑色 `#30302E`。
- 次要說明、單位、選填提示與圖表標籤使用深灰 `#514E49`。
- 白字保留給莓紅實心按鈕；淺色底上的文字使用深色。

## 2. 配色系統

### 文字與中性色

| Token | 色碼 | 使用方式 |
| --- | --- | --- |
| `--hj-text` | `#30302E` | 頁面與區塊標題、主要數值、清單名稱、輸入值、設定數值 |
| `--hj-muted` | `#514E49` | 次要說明、單位、提示、營養素目標、圖例、未選取導覽文字 |
| `--hj-placeholder` | `#625E58` | 輸入框預留文字；固定 opacity 1 |
| `--hj-disabled-ink` | `#776D65` | 停用日期箭頭；使用明確顏色，固定 opacity 1 |
| `--hj-ink` | `#3E3A39` | 容器、按鈕與圖示的深色線條 |
| `--hj-line` | `#E7DFD5` | 列分隔線、圖表網格、次要輸入邊線 |
| `--hj-paper` | `#FFFCF6` | 全頁暖米白背景 |
| `--hj-white` | `#FFFFFF` | 清單卡片、輸入框、莓紅按鈕文字 |

| Token | 色碼 | 使用方式 |
| --- | --- | --- |

### 文字對比與層級

- 主要文字與次要文字在目前六種淺色表面上，計算所得最低對比分別約為 **10.78:1** 與 **6.75:1**。此結果依固定色碼計算，未包含未來新增的透明度或背景。
- 標題明確指定 `color: var(--hj-text)`，避免受宿主頁面的標題顏色影響。
- 品牌莓紅、完成綠與警示棕保留既有狀態含義；狀態同時顯示文字或圖示。

## 3. 字體與字級

一般文字使用 **Huninn**，搭配系統中文字體 fallback。數字使用 `ui-rounded`、`SF Pro Rounded` 與系統字體 fallback，並設定 `font-variant-numeric: tabular-nums`。

| 角色 | 字級 | 使用範圍 |
| --- | --- | --- |
| 主頁標題 | 28 px | 身形追蹤、餐點、訓練、設定 |
| stepper 內容標題 | 24 px | 量身形、個別餐點、當天訓練 |
| 日期標題 | 21 px；窄螢幕 18 px | 日期左右切換中間標題 |
| 區塊標題 | 17 px | 每日目標、公用課表、一週排程 |
| 清單名稱 | 15 px；訓練動作 14 px | 食物、餐點、課表、動作名稱 |
| 摘要目標熱量 | 22 px；窄螢幕 20 px | 收合摘要中的目標數值 |
| 剩餘／超出熱量 | 19 px；窄螢幕 18 px | 收合摘要中的目前狀態 |
| 營養素數值 | 20 px；食物展開區 21 px | 蛋白質、脂肪、碳水 |
| 身形指標 | 25 px；窄螢幕 22 px | 週平均、差值、腰圍 |
| 輸入文字 | 16 px | 數字、日期、時間與表單輸入 |
| 次要文字 | 11–13 px | 單位、提示、圖例、標籤、導覽 |

- 以字級與位置建立層級；一般字重 400，少數強調數值可用 500。
- 一般段落行高約 1.5–1.65；日期行高 1.4；標題約 1.3–1.45。
- 數字維持對齊與固定單位格式，例如 `1,874 大卡`、`81.0 kg`、`87.8 cm`。
- 不透過降低整段 opacity 來區分次要文字。

## 4. 線條、圓角與留白

| 元件 | 線條 | 圓角與間距 |
| --- | --- | --- |
| 一般清單容器 | 2 px，深色線條 | 21 px 圓角；容器下方 15 px |
| 餐點／課表卡片 | 1.5 px，深色線條 | 19 px 圓角；下方 11 px |
| 熱量摘要 | 2.5 px，深色線條 | 18 px 圓角 |
| 主要按鈕 | 2 px，深色線條 | 13 px 圓角；高度至少 47 px |
| 次要按鈕 | 1.5 px，深色線條 | 11 px 圓角；高度至少 44 px |
| 輸入框 | 1.5 px，深色線條 | 10 px 圓角；內距約 10 × 11 px |
| 列分隔線 | 1 px，`--hj-line` | 容器內水平分隔 |
| 進度條 | 使用填色與淺色軌道 | 7 px 高，營養素 5 px；圓角 8 px |

- 頁面左右內距 20 px；360 px 以下縮為 14 px。
- 容器內距常用 15–18 px；一般清單列約 15 × 16 px，最小高度 66 px。
- 以平面色塊與線條呈現容器；選取 stepper 使用淡粉色外環。
- 預覽手機框為 3 px 線條、30 px 圓角、最大寬度 426 px；這是展示外框，不是原生 App 內容的一部分。

## 5. 圖示與導覽

- 使用同一套 Lucide 線條圖示；一般圖示約 19 px，線寬約 2.2。
- 清單箭頭 15 px；stepper 內部圖示 14 px；頁面裝飾徽章圖示 27 px。
- Icon-only 操作需有 accessible label，例如「前一天」「後一天」。
- 底部導覽維持「今天、身形、餐點、訓練、設定」五項；選取項為莓紅文字與淡粉底。
- 有效點擊區約 44 × 44 px 以上。建議在正式實作時，為小型 checkbox 擴大可點擊標籤區。

## 6. 核心元件與互動

### 每日熱量摘要

- 摘要與 stepper 在內容捲動時維持置頂。
- 預設收合，仍顯示目標、剩餘／超出、已吃熱量、熱量進度與訓練加回。
- 點擊目標熱量列展開蛋白質、脂肪、碳水的攝取量、目標、進度與差額。
- 展開後顯示「原目標 + 訓練加回」的目標組成。
- 展示例：原目標 1,748 + 訓練加回 126 = 1,874 大卡；已吃 1,016，還可以吃 858 大卡。
- 超出時顯示「超出目標」與差額；進度填色最多 100%，實際已吃數值完整保留。
- 訓練熱量在完成後加回，重複完成同一筆示意訓練不重複累加。

### 日期切換

- 左右箭頭切換前一天／後一天，中間顯示月、日與星期。
- 到今天時停用後一天箭頭；深灰停用樣式仍可辨識。
- 日期變更後保留目前選取的 stepper 與摘要展開狀態。
- 每一天獨立顯示餐點、份量、訓練與身形紀錄；沒有資料的日期顯示空狀態。

### Stepper

- 固定順序：量身形 → 早餐 → 午餐 → 訓練 → 晚餐。
- 點擊切換下方內容；目前選取項有莓紅線條、淡粉外環與文字底色。
- 已完成為淡綠圓點與勾號；略過為淡黃圓點與減號；未完成保留米白底。
- 「選取」與「完成」是不同狀態，使用者可查看已完成或尚未完成的任一步驟。

### 餐點與訓練清單

- 列內左側為名稱與簡短說明，右側為份量、熱量或組數，再加箭頭。
- 食物列先展開個別營養素，再提供「調整份量」操作。
- 修改份量同步更新該食物、該餐與該日期的營養摘要。
- 訓練動作列展開重量、次數與完成紀錄；不同日期的組數資料各自保存。

### 量身形表單

- 體重為必填；腰圍清楚標示「選填」，使用 cm。
- 可以只儲存體重；沒有填腰圍時不阻擋送出，也不建立零值紀錄。
- 選填提示使用深灰文字「不用每天量，有量再記錄。」
- 儲存成功回饋明確指出已儲存的欄位。

## 7. 響應式與可讀性

- 以 320–426 px 手機內容寬度為主要範圍，較寬畫面將預覽置中。
- 窄螢幕調整字級與內距；主要操作、日期、熱量摘要與 stepper 持續可用。
- 長名稱依可用空間換行，保留數值與單位的對齊。
- 顏色之外，同時用標籤、勾號、減號與箭頭表達狀態。
- 保留鍵盤焦點樣式，表單使用原生控制項與對應 label。

## 8. 可直接沿用的 CSS Tokens

```css
:root {
  --hj-text: #30302e;
  --hj-muted: #514e49;
  --hj-placeholder: #625e58;
  --hj-disabled-ink: #776d65;
  --hj-ink: #3e3a39;
  --hj-line: #e7dfd5;
  --hj-paper: #fffcf6;
  --hj-white: #ffffff;
  --hj-berry: #a32b64;
  --hj-pink: #f6e3ec;
  --hj-yellow-soft: #fff2d7;
  --hj-green: #e3efd9;
  --hj-green-ink: #30694d;
  --hj-purple: #eee5f8;
  --hj-purple-ink: #7450a5;
  --hj-warning-ink: #89580e;
  --hj-warning-fill: #b17b23;
}

.app {
  color: var(--hj-text);
  background: var(--hj-paper);
  font-family: 'Huninn', -apple-system, BlinkMacSystemFont, sans-serif;
}

.app h2, .app h3, .app .row-title {
  color: var(--hj-text);
}

.app .secondary-text { color: var(--hj-muted); }
.app input::placeholder { color: var(--hj-placeholder); opacity: 1; }
.app .number {
  font-family: ui-rounded, 'SF Pro Rounded', -apple-system, sans-serif;
  font-variant-numeric: tabular-nums;
}
```

上述示範將 tokens 放在 `:root`；正式整合時可移到 App 根節點，避免影響其他頁面。`--hj-warning-ink` 與 `--hj-warning-fill` 是對目前既有棕色值的語意命名，方便開發沿用。
